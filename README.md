**🔐 Secure Keypad Password Generator**

A secure password system that combines random password generation with a dynamic virtual keypad to prevent shoulder surfing and pattern-based attacks.

**🚀 Overview**

This project implements a virtual keypad-based authentication system where users enter passwords using on-screen buttons instead of a keyboard.

The keypad layout reshuffles every 30 seconds, making it difficult for attackers to track input patterns, while a random 6-character password is generated for secure access.

**✨ Key Features**
🔄 Dynamic Keypad Shuffling (Every 30s)
🔐 Random Password Generation (6 characters)
🚫 Keyboard Input Disabled for Security
✅ Real-time Authentication Feedback
🎨 Interactive UI with Animations
🌙 Dark Mode Toggle
🧹 Clear & Backspace Controls

**🛠️ Tech Stack**
HTML5 – Structure
CSS3 – Styling, Grid & Flexbox, Themes
JavaScript (Vanilla JS) – Logic, DOM manipulation, shuffling & validation
